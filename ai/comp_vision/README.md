# Visión computacional

- [chick-monitor](chick-monitor/README.md): detección experimental de pollitos y
  conteo visible sobre la cámara del dashboard. Incluye adaptador, modelos,
  evaluación y espacios para seguimiento y comportamiento.
- `human-detector/`: modelo histórico para detección de personas.
- `emotion-detector/`: integración histórica de rostros y expresiones.

Los modelos y algoritmos visuales pertenecen a esta carpeta. Los lanzadores de
servicios están en `scrips/` y `sh/`; la API y la interfaz en `backend/` y `frontend/`.
